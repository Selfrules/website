## How to Use This Library

### Intensity Levels

| Level | Description | When to Use | Voice Calibration |
|-------|-------------|-------------|-------------------|
| **Soft** | Passive suggestion, educational framing, low pressure | Newsletter, blog CTAs, first-time visitors, content upgrades | 50% Romei / 30% Toon / 20% Sinek |
| **Medium** | Clear ask with benefit emphasis, moderate urgency | Service pages, discovery calls, return visitors | 60% Romei / 25% Toon / 15% Sinek |
| **High** | Direct call with urgency/specificity, scarcity elements | Primary conversion points, booking CTAs, high-intent pages | 70% Romei / 20% Toon / 10% Sinek |

### CTA Structure Pattern

Every optimized CTA follows: **Action + Benefit + Time + Effort Reduction**

- **Specific Action**: "Download", "Book", "Get", "Scopri" (not "Click here", "Submit")
- **Clear Benefit**: Measurable outcome ("identify 3 bottlenecks")
- **Low Commitment**: Time/cost framing ("15 minuti", "free", "zero pitch")
- **Reduced Friction**: Simplicity signals ("1 page", "no email required", "instant")

### Value Equation Reference

```
Value = (Dream Outcome x Perceived Likelihood) / (Time Delay x Effort & Sacrifice)
```

Every CTA is annotated with which Value Equation component it primarily optimizes.
