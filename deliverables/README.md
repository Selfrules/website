## 📚 Voice Framework Reference

**Tone of Voice:** Pragmatic Provocateur (Romei/Toon/Sinek blend)

- **Romei (50-70%):** Clarity through subtraction, definitive statements, no jargon
- **Toon (20-30%):** Accessibility through honesty, relatable details, permission-giving
- **Sinek (10-20%):** Purpose through connection, "why" anchors, transformation framing

**Quick Quality Check:**
- Romei: Can I cut 20% more words? Is there a "this is wrong" moment?
- Toon: Would a friend say this? Is there a "that's me!" recognition?
- Sinek: Is the "why" connected? Does it end with hope/possibility?

See full framework: [selfrules-tov-framework.md](./selfrules-tov-framework.md)
