## CTA Optimization Methodology

### Intensity Levels
| Level | Description | When to Use |
|-------|-------------|-------------|
| **Soft** | Passive suggestion, educational framing, low pressure | Newsletter, blog CTAs, content upgrades |
| **Medium** | Clear ask with benefit emphasis, moderate urgency | Service pages, discovery calls |
| **High** | Direct call with urgency/specificity, scarcity elements | Primary conversion points, booking CTAs |

### CTA Structure Pattern
Every optimized CTA follows: **Action + Benefit + Time + Effort Reduction**

- **Specific Action**: "Download", "Book", "Get", "Scopri" (not "Click here", "Submit")
- **Clear Benefit**: Measurable outcome ("identify 3 bottlenecks")
- **Low Commitment**: Time/cost framing ("15 minuti", "free", "zero pitch")
- **Reduced Friction**: Simplicity signals ("1 page", "no email required", "instant")
