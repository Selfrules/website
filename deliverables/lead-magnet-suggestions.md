## Lead Magnet Methodology

### Hook-Retain-Reward Structure

Every lead magnet must follow this structure:

| Phase | Purpose | Implementation |
|-------|---------|----------------|
| **Hook** | Capture attention with specific problem recognition | Headline that mirrors internal dialogue |
| **Retain** | Keep engagement through immediate value delivery | Quick win within first 2 minutes |
| **Reward** | Deliver transformation that creates desire for more | Clear outcome + natural bridge to paid service |

### Lead Magnet Quality Criteria

1. **Specificity**: Solves ONE problem, not "general PM tips"
2. **Speed**: Delivers value in <5 minutes (or clear time commitment)
3. **Actionability**: User can implement immediately, no prerequisites
4. **Alignment**: Naturally leads to the corresponding service tier
5. **Low Friction**: Micro-commitment (email only, no forms, instant access)

### Lead Magnet Types by Conversion Goal

| Type | Best For | Friction Level | Conversion Path |
|------|----------|----------------|-----------------|
| **Downloadable Resource** | List building, brand awareness | Lowest | Newsletter → Nurture → Discovery Call |
| **Email Sequence** | Education + trust building | Low | Sequence → Specific Service → Booking |
| **Assessment/Audit** | Qualification + personalization | Medium | Audit → Customized Recommendation → Call |
| **Mini-Course/Webinar** | High-intent leads | Higher | Course → Application → Consultation |

## LEAD MAGNET 1: PM Prioritization Template

### Service Alignment: Strategic Consulting (90 min)

**Target Audience:** Overwhelmed PMs with too many features, no priorities
**Problem Statement:** "Roadmap piena ma niente priorita?"

### Hook-Retain-Reward Structure

#### HOOK (Capture Attention)

**Italian:**
```
[Blocco modulare | Lead Magnet Hook IT]

Headline: "4 feature in sviluppo, nessuna finita? Ecco il template che uso per decidere quale finire prima."

Subheadline: "Lo stesso framework che ha ridotto il time-to-ship del 40% per TechFlow AI."

Promise: "5 minuti di compilazione → 1 priorita' chiara per lunedi'"
```

**English:**
```
[Blocco modulare | Lead Magnet Hook EN]

Headline: "4 features in development, none finished? Here's the template I use to decide which one to finish first."

Subheadline: "The same framework that cut time-to-ship by 40% for TechFlow AI."

Promise: "5 minutes to fill → 1 clear priority for Monday"
```

#### RETAIN (Keep Engagement)

**Template Structure:**
1. **Page 1:** Feature Impact Matrix (Business value × Technical effort)
2. **Page 2:** Stakeholder Alignment Scorecard (Who wants what, why)
3. **Page 3:** "Monday Action" Decision Tree (If X, then prioritize Y)

**Quick Win Delivery:**
- Within first 2 minutes: User identifies their #1 priority
- Value realization: "Oh, I've been prioritizing the wrong thing"

#### REWARD (Create Desire for More)

**Transformation Delivered:**
- From: "Everything is urgent, nothing moves"
- To: "I know what to ship first, and why"

**Natural Bridge to Service:**
```
[Nota | Conversion Bridge IT]

"Questo template ti da' 1 priorita' per lunedi'.
La consulenza strategica ti da' il sistema per non averne mai piu' bisogno.
90 minuti → decisioni chiare per i prossimi 3 mesi."

[LINK_BOOKING_90MIN]
```

### Lead Magnet Specs

| Attribute | Value |
|-----------|-------|
| **Format** | PDF (fillable) or Notion template |
| **Pages** | 3 pages (max) |
| **Time to value** | 5 minutes |
| **Gate** | Email only (no name, no company) |
| **File name** | `pm-prioritization-template-selfrules.pdf` |
| **Delivery** | Instant download (no drip) |

### Objection Pre-Handling Within Lead Magnet

| Objection | How Template Addresses |
|-----------|------------------------|
| **"My case is different"** | Page 2 includes 3 scenario examples: B2B SaaS, Consumer app, Enterprise |
| **"Won't work for my team"** | Matrix is team-agnostic, works solo or with stakeholders |
| **"Takes too much time"** | 5-minute promise is explicit, no lengthy instructions |

## LEAD MAGNET 3: PM Pattern Audit (Self-Assessment)

### Service Alignment: PM Mentorship (monthly)

**Target Audience:** Growing PMs who suspect they're repeating mistakes
**Problem Statement:** "Ogni progetto ripete il caos?"

### Hook-Retain-Reward Structure

#### HOOK (Capture Attention)

**Italian:**
```
[Blocco modulare | Lead Magnet Hook IT]

Headline: "Scopri i 5 blind spot che il 90% dei PM non vede (fino a quando costa 3 mesi)."

Subheadline: "2 minuti di assessment → una mappa dei pattern che ti fanno girare in tondo."

Promise: "Nessuno te li dira' mai. Questo audit si'."
```

**English:**
```
[Blocco modulare | Lead Magnet Hook EN]

Headline: "Discover the 5 blind spots 90% of PMs don't see (until it costs them 3 months)."

Subheadline: "2-minute assessment → a map of patterns keeping you spinning in circles."

Promise: "No one will ever tell you. This audit will."
```

#### RETAIN (Keep Engagement)

**Audit Structure (10 questions):**

1. **Pattern 1: Over-documentation**
   - "Quante ore a settimana scrivi documenti che nessuno legge?"

2. **Pattern 2: Stakeholder Pleasing**
   - "Quante volte questa settimana hai detto 'si'' quando intendevi 'devo pensarci'?"

3. **Pattern 3: Technical Avoidance**
   - "Quando un dev ti dice 'e' complesso', quanto spesso chiedi 'perche''?"

4. **Pattern 4: Roadmap Theater**
   - "La tua roadmap riflette cosa stai costruendo o cosa volevi costruire 3 mesi fa?"

5. **Pattern 5: Meeting Multiplication**
   - "Quanti meeting questa settimana potevano essere un messaggio Slack?"

**Scoring Mechanism:**
- 0-3: "Sei piu' consapevole del 70% dei PM"
- 4-6: "Ci sono pattern che ti costano tempo (ma puoi fixarli)"
- 7-10: "I tuoi blind spot stanno guidando il progetto (parliamone)"

**Quick Win Delivery:**
- Immediate: User sees themselves in at least 2 patterns
- Emotional impact: "I do that. I didn't realize."

#### REWARD (Create Desire for More)

**Transformation Delivered:**
- From: "I don't know what I don't know"
- To: "I can name my patterns (first step to fixing them)"

**Natural Bridge to Service:**
```
[Nota | Conversion Bridge IT]

"L'audit ti mostra i pattern. La mentorship ti insegna a riconoscerli in 5 minuti, non in 5 mesi.
90 giorni → i blind spot diventano automatismi. Poi non mi servi piu'."

[LINK_MENTORSHIP_APPLY]
```

### Lead Magnet Specs

| Attribute | Value |
|-----------|-------|
| **Format** | Interactive quiz (Typeform/Tally) OR PDF self-assessment |
| **Questions** | 10 questions, 2-minute completion |
| **Time to value** | Instant (score + personalized feedback) |
| **Gate** | Email for results delivery |
| **Output** | PDF report with personalized pattern analysis |
| **Follow-up** | 3-email sequence with pattern-specific tips |

### Objection Pre-Handling Within Audit

| Objection | How Audit Addresses |
|-----------|---------------------|
| **"I already know my weaknesses"** | Questions reveal unconscious patterns, not obvious ones |
| **"This feels like a sales funnel"** | Results are genuinely useful regardless of service purchase |
| **"I'm too senior for this"** | Questions reference senior-level scenarios (exec alignment, architecture decisions) |

## APPENDIX: Lead Magnet Content Outlines

### A. Prioritization Template (Full Outline)

**Page 1: Feature Impact Matrix**
- Row: Feature name
- Column 1: Business Impact (1-10)
- Column 2: Technical Effort (1-10)
- Column 3: Stakeholder Alignment (1-10)
- Column 4: Priority Score (auto-calculated)
- Instructions: "Start with your top 5 features. Fill honestly. The matrix doesn't lie."

**Page 2: Stakeholder Alignment Scorecard**
- Row: Stakeholder name/role
- Column 1: What they want
- Column 2: Why they want it
- Column 3: Alignment with current priority (Y/N)
- Instructions: "If Column 3 has >2 'N's, you have an alignment problem, not a prioritization problem."

**Page 3: Monday Action Decision Tree**
```
IF highest Priority Score feature has stakeholder misalignment:
  → Fix alignment before shipping

IF two features have same Priority Score:
  → Choose the one with lower Technical Effort

IF Technical Effort is same:
  → Choose the one that unblocks other features

DEFAULT:
  → Ship highest Priority Score. Period.
```

### B. PM Pattern Audit (10 Questions)

1. Quante ore questa settimana hai passato a scrivere documenti? (0-2 / 3-5 / 6-10 / 10+)
2. Quante volte questa settimana hai detto "si'" quando pensavi "devo pensarci"? (0 / 1-3 / 4-7 / 8+)
3. Quando un dev dice "e' complesso", quanto spesso chiedi "perche'"? (Sempre / Spesso / A volte / Mai)
4. La tua roadmap di 3 mesi fa quanto e' accurata oggi? (Identica / 70% accurata / 50% / Non la guardo)
5. Quanti meeting questa settimana potevano essere un messaggio? (0 / 1-3 / 4-7 / 8+)
6. Quanto spesso il designer e il developer hanno interpretazioni diverse della stessa feature? (Mai / Raramente / Spesso / Sempre)
7. Quando c'e' un conflitto stakeholder, chi decide? (Io con dati / Il piu' senior / Nessuno / Dipende)
8. Quanto tempo passa tra "idea" e "prima riga di codice"? (<1 settimana / 2-4 settimane / 1-2 mesi / 3+ mesi)
9. Quanto spesso scopri problemi di fattibilita' DOPO che il design e' approvato? (Mai / Raramente / Spesso / Ogni volta)
10. Se dovessi riscrivere la tua ultima user story, quante cose cambieresti? (Niente / 1-2 cose / 3-5 / La riscriverei da zero)

**Scoring:**
- Opzione 1 = 0 punti
- Opzione 2 = 1 punto
- Opzione 3 = 2 punti
- Opzione 4 = 3 punti

**Results Interpretation:**
- 0-7: "Sei piu' consapevole del 70% dei PM. I tuoi pattern sono sotto controllo."
- 8-15: "Alcuni pattern ti costano tempo. La buona notizia: sono fixabili."
- 16-23: "I pattern stanno guidando i tuoi progetti. Serve un occhio esterno."
- 24-30: "Parliamone. Questi pattern non si fixano da soli."
