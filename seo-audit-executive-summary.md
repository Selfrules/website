## Top 3 Critical Issues

### 1. Missing Technical Foundations (robots.txt + sitemap.xml)
Both return 404. Search engines have no crawl directives and no page discovery mechanism. Only 1 page is indexed by Google.
- **Fix:** Create both files (1.5 hours)
- **Impact:** Crawlability 60 → 95

### 2. Zero Structured Data (JSON-LD Schema)
No Person, WebSite, Article, or FAQ schemas implemented. Zero rich snippets possible. No competitor in the niche uses structured data either — first-mover advantage available.
- **Fix:** Implement Person + WebSite schemas (4 hours)
- **Impact:** Rich snippets eligibility + Knowledge Panel

### 3. Broken Trust Signals (Privacy/Terms 404)
Privacy Policy and Terms of Service pages linked in footer return 404. This is a **GDPR compliance violation** for an EU-based site collecting user data via contact forms.
- **Fix:** Create both legal pages (8 hours)
- **Impact:** Trust score 2/5 → 3/5
