## Part 3: LinkedIn Formatting Best Practices

### 3.1 Visual Structure Rules

| Element | Guideline | Why |
|---------|-----------|-----|
| **Line Breaks** | Double-space between sections | Mobile readability |
| **Emojis** | Max 3-5 per post, functional only | Scanability without distraction |
| **Lists** | Use → or - for bullets, numbered for sequences | Clear hierarchy |
| **Checkmarks** | ✅ for positive, ❌ for negative | Quick visual scanning |
| **Bold Text** | Not available in LinkedIn - use caps sparingly | Emphasis |
| **Hashtags** | 3-5 max, at end | Not mid-text |
| **Links** | In comments or "link in bio" | Algorithm doesn't penalize |

### 3.2 Character Count Guidelines

| Post Type | Optimal Length | Maximum |
|-----------|----------------|---------|
| Story/Value Post | 800-1200 chars | 1500 chars |
| Framework Post | 900-1100 chars | 1300 chars |
| Question Post | 400-700 chars | 800 chars |
| Poll Post | 300-500 chars | 600 chars |
| Contrarian Post | 700-1000 chars | 1200 chars |
| Promotional Post | 700-1000 chars | 1200 chars |

### 3.3 Opening Line Impact

```
FIRST LINE OPTIMIZATION
===============================================================================

The first 150-200 characters must:
- Create curiosity
- Stop the scroll
- NOT be clickbait (ruins trust)

EFFECTIVE OPENERS:
✅ "Unpopular opinion: [contrarian view]"
✅ "[Quantified failure] taught me [lesson]"
✅ "[Question that resonates]?"
✅ "I made [mistake] so you don't have to"
✅ "Stop doing [common thing]. Here's why:"

INEFFECTIVE OPENERS:
❌ "I wanted to share some thoughts on..."
❌ "Happy to announce that..."
❌ "Excited to be part of..."
❌ "BREAKING:"
❌ "🚨 MUST READ 🚨"

===============================================================================
```

### 4.2 Weekly Hook Distribution

For sustainable content creation, distribute hook formula categories across the week:

| Day | Primary Hook Category | Secondary | Reason |
|-----|----------------------|-----------|--------|
| **Monday** | VULNERABILITY (B) or CONTRARIAN (A) | LIST (D) | Strong week opener |
| **Wednesday** | QUESTION (C) or SCENARIO (F) | RITUAL (G) | Mid-week engagement boost |
| **Thursday** | HOW-TO (E) or LIST (D) | - | Value-focused |
| **Friday** | HOW-TO (E) + soft CTA or TRANSPARENCY (H) | - | Week close + conversion |

### 4.3 30-Day Hook Formula Rotation

**Week 1-2 (Foundation):** Focus on B, D, E hooks (vulnerability, lists, how-to)
- Build trust through failures and practical value
- Avoid aggressive contrarian takes until voice is established

**Week 3-4 (Expansion):** Add A, F, G hooks (contrarian, dilemmas, rituals)
- Introduce debate once trust is established
- Launch community rituals
- Use dilemmas to drive engagement
